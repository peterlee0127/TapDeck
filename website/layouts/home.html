GETTING STARTED

Install it.
Then close it.

Once you’ve chosen your gestures, close the settings window. The app keeps working in the background.

Need to change something? Open TapDeck again from Finder or Spotlight.

  1. Move the app to Applications.

    Download the DMG from GitHub Releases, open it, and drag TapDeck into your Applications folder.

  2. Allow Accessibility access.

    Open the app, then enable it in System Settings → Privacy & Security → Accessibility. This lets it send your chosen mouse clicks and keyboard shortcuts.

  3. Try a three-finger tap.

    Use the Test page to check recognition first. Test mode shows the result without performing the action.

A FEW DETAILS

Before you install.

Something not covered here?
Open an issue on GitHub ↗

Which trackpads work?+

A built-in Mac trackpad or Apple Magic Trackpad, on macOS 14 Sonoma or later. Multi-finger physical clicks need pressure support. One-finger Force Click requires a Force Touch trackpad.

Can I map a gesture to an app?+

Yes. Select “Open or Switch to App” in a gesture’s action menu, then choose an application. TapDeck opens it if needed, or brings its windows forward if it is already running. You can also choose Left, Middle, or Right Click, Quick Look, Mission Control, App Exposé, or Show Desktop.

What if three fingers also trigger Look Up?+

Turn off “Look up & data detectors” in macOS Trackpad settings, or disable the three-finger tap in TapDeck. Each gesture can be enabled or disabled independently.

Does anything leave my Mac?+

No. Touch processing, preferences, and optional activity logs stay on your Mac. The app has no networking code, analytics, or cloud dependency. Activity logging is off by default.

How do I quit the background app?+

Reopen TapDeck from Finder or Spotlight, then choose Advanced Settings → More → Quit App.

Why isn’t it on the Mac App Store?+

Global multi-finger recognition uses Apple’s private MultitouchSupport framework, so the app is distributed directly through GitHub. macOS updates can affect recognition; check the release notes when updating your system.
